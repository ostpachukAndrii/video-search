# Ваги моделей

У git тут лежить **тільки** `manifest.lock`. Самі ваги приїжджають на етапі
збірки образу — див. `Dockerfile`, фаза `builder`.

## Чому так

Середовище виконання не має доступу до інтернету (вимога п.9). Отже:

* завантажити ваги там неможливо — треба покласти їх заздалегідь;
* покласти «якісь» ваги недостатньо: результати пошуку йдуть у матеріали
  справи, тож образ має бути відтворюваним побайтово.

Звідси два правила маніфесту:

1. `revision` — **завжди 40-символьний commit SHA**. Тег можна перезаписати,
   commit — ні.
2. `sha256` на кожен файл. Розбіжність валить збірку образу.

## Локальна робота

```bash
# закріпити ревізії та порахувати контрольні суми (потрібна мережа)
python scripts/fetch_models.py --update-lock

# завантажити обовʼязкові моделі
python scripts/fetch_models.py

# додати опційні (so400m, Florence-2-large, whisper) — образ виросте в рази
python scripts/fetch_models.py --include-optional

# звірити суми без мережі
python scripts/fetch_models.py --check
```

## Стан ліцензій

`python scripts/check_licenses.py` — інвентар. Наразі один блокер:
`face_embed_sface` має стан `UNVERIFIED`, тому модуль облич лишається за
фіче-флагом, доки походження ваг не підтвердить юрист.
